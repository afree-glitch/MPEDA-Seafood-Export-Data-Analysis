
# 📊 MPEDA Seafood Export Data Analysis

## 📌 Project Overview

Exploratory Data Analysis of India's seafood export data from **2015–16 to 2024–25**, focusing on export quantity, export value, product-wise performance, growth, trends, correlations, and distributions.

## 🎯 Objectives

* Analyze seafood export quantity and value over the years
* Compare performance across major seafood categories
* Analyze year-on-year export growth
* Study seafood export composition
* Identify relationships and trends in the data
* Perform correlation, distribution, and outlier analysis

## 🛠️ Tools & Technologies

**Python | Google Colab | Pandas | NumPy | Matplotlib | Seaborn**

## 🔍 Analysis Performed

* Total export value and quantity trends
* Average export quantity and value by product category
* Seafood export composition
* Year-on-year export growth
* Frozen shrimp quantity vs. export value
* Correlation analysis
* Distribution and outlier analysis
* Major seafood product trends

## 📈 Key Insights

The analysis provides a data-driven view of India's seafood export performance by examining changes in export quantity, export value, product categories, and yearly trends.
